NeoFabric
===========

## 关于本项目

NeoFabric 本质上就是一个图一乐的东西，基本上就是一个 Fabric。
若您发现此加载器与 Fabric 存在致命的一致性，请不要怀疑您的发现。

## 使用前须知

- 仅支持 Minecraft 1.20.1。
- 本加载器仅支持特别定制的 NeoFabric 模组（尽管一个都没有），请勿把普通的 Fabric 模组放入其中。
- 不需要单独安装 Fabric API，里面内置了。
- 这东西本质是图一乐，若有报错，请谅解。
